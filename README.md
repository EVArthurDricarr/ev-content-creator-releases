# EV Content Creator — versões

O montador de carrosséis da **EV Digital**. Este repositório guarda só as
**versões publicadas** do app; o código fica em repositório privado.

## Baixar

Abra **[Releases › a versão mais recente](https://github.com/EVArthurDricarr/ev-content-creator-releases/releases/latest)**
e baixe o arquivo `EV-Content-Creator-…-instalador.exe`.

## Instalar no Windows

1. Dê dois cliques no instalador.
2. O Windows vai mostrar **"O Windows protegeu o computador"**. Não é vírus
   nem defeito: aparece com todo programa que ainda não tem certificado pago
   de assinatura. Clique em **Mais informações** e depois em **Executar assim
   mesmo**.
3. Escolha a pasta (a sugerida está ótima) e clique em **Instalar**.

## Atualizar

**O app faz sozinho.** Quando sai uma versão nova, ele baixa em segundo plano
(só o pedaço que mudou) e mostra o botão laranja **Atualizar app** na tela
inicial. Se você não clicar, ele instala na próxima vez que o app fechar.

Só a primeira instalação é feita à mão: daí em diante as atualizações chegam
por aqui.

## Deu problema?

Conte no grupo da equipe: o que você estava fazendo e o que apareceu na tela
(um print ajuda). Se for na atualização, mande também o arquivo
`atualizacao.log` da pasta de dados do app.
